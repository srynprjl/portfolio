# Portfolio

This is my personal portfolio website built to showcase my work, skills, and projects. It is designed to be clean, minimal, responsive, and easy to navigate.

## Technologies Used

The project is built with the following tools and frameworks:

- React + TypeScript + Vite
- Tailwind CSS
- React Icons

## Features

- Home section with a typewriter effect for personal titles.
- About section highlighting my background as a Computer Science student.
- Skills section showcasing proficiency in various programming languages and tools.
- Projects section with links to live demos and source code.
- Social media integration for easy contact.

## Getting Started

To run this project locally, follow these steps:

1. Clone the repository to your local machine.
2. Install the dependencies using your preferred package manager (e.g., npm, pnpm, or bun).
3. Start the development server with the dev command.

```bash
# Install dependencies
bun install

# Run the project
bun run dev
```

The application will be available at http://localhost:5173 by default.

## Building for Production

To create a production-ready build, run the following command:

```bash
bun run build
```

The optimized files will be generated in the dist directory.
